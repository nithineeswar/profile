Appearance Based Terrain Learning And Classification For Autonomous Mobile Robot Navigation, advised by Prof. Prabhakar Mishra, CISL, PESIT (2013--2015)
Nithin Eswarappa
Evaluated 15 visual feature representations (5 color spaces, 5 texture descriptors, and com- binations) across GMM and MLP classifiers. Implemented a scalable MLP framework from scratch (configurable lay- ers, neurons, and a generalized backpropagation routine) to systematically search 3 architectures per feature; trained via stochastic gradient descent with momentum and layer-wise learning rate scheduling, using validation-based early stopping and cross-dataset generalization testing. A key contribution of the work is the development of a calibrated pixel-to-floor homography projection module that transforms 2D semantic classifications into a 3D rover-centric met- ric map, effectively converting high-level visual data into actionable spatial information for physical path planning. This work provides a scalable perception pipeline that bridges the gap between raw computer vision and reliable robotic mobility in real-world settings (Grade: 190/200)
